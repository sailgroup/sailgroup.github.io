Invisible to sighted users (metadata). The lab and the PI carry stable "@id"s (/#organization, /pi/#person), and the other mentions of them in this file repeat that @id (the home page's founder, a person's worksFor or alumniOf, and the PI in a paper's author list, matched on pi.yml `name` or `name_full` as the bold PI name is), so search engines join the mentions into one lab and one person. jekyll-seo-tag's own block names the lab without an @id. sameAs lists only profiles of the entity itself: the PI's Scholar, ORCID and GitHub pages sit on the PI, never on the lab; the lab's is its GitHub organization. The lab's other names (_config.yml `alternate_names`, among them the Korean name in Kookmin University's faculty directory) and Kookmin University's Korean name are here for search engines only; no page shows them.
