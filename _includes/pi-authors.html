{%- comment -%} Highlights selected names (bold, .pi) inside an author string, and links the lab's people. Scope is deliberate, so the same paper marks a different name per context: - default (no `person`): highlight the PI only (site.data.pi.name / name_full). Used on the Publications list and each publication detail page -- a paper on the lab's list emphasises the lab's PI, not every co-author who is a member. - with `person=`: highlight ONLY that person (their `name` and any `author_aliases`, e.g. an abbreviated "H Kim"). Used on a person's own page, so each author list marks just the page owner. With `link=true` (a lab paper: the Publications list, a paper's page, and the lab papers on a person's page) the name of anyone with a page on the site links to it (D67): the PI to /pi/, a member or alumnus to /people//, matched exactly on the names above (the names that put the paper on that person's page, member-pubs.html). A page never links to itself, so on a person's page their own name stays bold and unlinked. A person's papers from elsewhere get no links: a common name there may be someone else. The links look like the other names until the pointer is on them (main.scss), so at rest the list still marks only the PI (D27). Pass: authors=, optionally person= and link=true. Each name is set in a no-wrap span with the comma outside it, so a line breaks only between two names (on phones it split "Joonyoung / F. Joung"); the `*` and `†` marks stay with their name, outside the bold and the link. The author strings are "A, B, C", so splitting at the commas and joining with ", " gives back the same text. {%- endcomment -%} {%- assign names = "" | split: "" -%} {%- if include.person -%} {%- assign person = include.person -%} {%- if person.name and person.name != "" -%}{%- assign names = names | push: person.name -%}{%- endif -%} {%- if person.author_aliases -%}{%- for al in person.author_aliases -%}{%- if al and al != "" -%}{%- assign names = names | push: al -%}{%- endif -%}{%- endfor -%}{%- endif -%} {%- else -%} {%- if site.data.pi.name and site.data.pi.name != "" -%}{%- assign names = names | push: site.data.pi.name -%}{%- endif -%} {%- if site.data.pi.name_full and site.data.pi.name_full != "" -%}{%- assign names = names | push: site.data.pi.name_full -%}{%- endif -%} {%- endif -%} {%- assign names = names | uniq -%} {%- assign parts = include.authors | split: "," -%} {%- for part in parts -%} {%- assign a = part | strip -%} {%- assign bare = a | remove: "*" | remove: "†" | remove: "‡" | strip -%} {%- assign label = bare -%} {%- if bare != "" and names contains bare -%}{%- capture label -%}{{ bare }}{%- endcapture -%}{%- endif -%} {%- if include.link and bare != "" -%} {%- assign href = "" -%} {%- if bare == site.data.pi.name or bare == site.data.pi.name_full -%}{%- assign href = "/pi/" -%} {%- else -%}{%- for m in site.data.people -%}{%- if href == "" and m.slug and m.slug != "" -%}{%- if bare == m.name or m.author_aliases contains bare -%}{%- assign href = "/people/" | append: m.slug | append: "/" -%}{%- endif -%}{%- endif -%}{%- endfor -%}{%- endif -%} {%- if href != "" and href != page.url -%}{%- capture label -%}{{ label }}{%- endcapture -%}{%- endif -%} {%- endif -%} {%- if label != bare -%}{%- assign a = a | replace_first: bare, label -%}{%- endif -%} {{ a }}{% unless forloop.last %}, {% endunless %} {%- endfor -%}
