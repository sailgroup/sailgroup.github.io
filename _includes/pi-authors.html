{%- comment -%} Highlights selected names (bold, .pi) inside an author string. Scope is deliberate, so the same paper marks a different name per context: - default (no `person`): highlight the PI only (site.data.pi.name / name_full). Used on the Publications list and each publication detail page -- a paper on the lab's list emphasises the lab's PI, not every co-author who is a member. - with `person=`: highlight ONLY that person (their `name` and any `author_aliases`, e.g. an abbreviated "H Kim"). Used on a person's own page, so each author list marks just the page owner. Pass: authors=, optionally person=. Each name is set in a no-wrap span with the comma outside it, so a line breaks only between two names (on phones it split "Joonyoung / F. Joung"); the `*` and `†` marks stay with their name. The author strings are "A, B, C", so splitting at the commas and joining with ", " gives back the same text. {%- endcomment -%} {%- assign names = "" | split: "" -%} {%- if include.person -%} {%- assign person = include.person -%} {%- if person.name and person.name != "" -%}{%- assign names = names | push: person.name -%}{%- endif -%} {%- if person.author_aliases -%}{%- for al in person.author_aliases -%}{%- if al and al != "" -%}{%- assign names = names | push: al -%}{%- endif -%}{%- endfor -%}{%- endif -%} {%- else -%} {%- if site.data.pi.name and site.data.pi.name != "" -%}{%- assign names = names | push: site.data.pi.name -%}{%- endif -%} {%- if site.data.pi.name_full and site.data.pi.name_full != "" -%}{%- assign names = names | push: site.data.pi.name_full -%}{%- endif -%} {%- endif -%} {%- assign names = names | uniq -%} {%- assign parts = include.authors | split: "," -%} {%- for part in parts -%} {%- assign a = part | strip -%} {%- for name in names -%}{%- capture rep -%}{{ name }}{%- endcapture -%}{%- assign a = a | replace: name, rep -%}{%- endfor -%} {{ a }}{% unless forloop.last %}, {% endunless %} {%- endfor -%}
