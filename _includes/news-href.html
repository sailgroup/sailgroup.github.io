{%- comment -%} The address a news item's `link` should point to. An old person address, /members// or /alumni//, still works (it is a redirect page), but it costs readers an extra page load and search engines a noindex hop, so it is printed as the person's own page /people// when that slug is in people.yml. news.yml itself is not changed, and every other link (lists like /members/, papers, full URLs) is returned exactly as written. Used by index.html, news.html, and llms-full.txt. Pass link=. {%- endcomment -%} {%- assign newslink = include.link | default: "" -%} {%- assign newsparts = newslink | split: "/" -%} {%- if newsparts.size == 3 and newsparts[0] == "" -%} {%- if newsparts[1] == "members" or newsparts[1] == "alumni" -%} {%- assign newsperson = site.data.people | where: "slug", newsparts[2] | first -%} {%- if newsperson -%}{%- assign newslink = "/people/" | append: newsparts[2] | append: "/" -%}{%- endif -%} {%- endif -%} {%- endif -%} {{- newslink -}}
