{%- comment -%} Google Scholar / Highwire Press citation_* meta for publication detail pages. Emits only when page.pid is set (the generated /publications// pages); every value comes from the same publications.yml entry the page renders, so the meta cannot drift from the visible citation. Helps Google Scholar and reference managers recognize each paper. No citation_pdf_url: the lab links to the DOI, not a self-hosted PDF. Only for a paper with a public version (a DOI or a preprint link): a manuscript that is still under review has neither, so there is nothing for Scholar to index, and its entry may shorten the author list with "...", which must never go out as an author name. {%- endcomment -%} {%- if page.pid -%} {%- assign p = site.data.publications | where: "id", page.pid | first -%} {%- assign citable = false -%} {%- if p.doi and p.doi != "" -%}{%- assign citable = true -%}{%- endif -%} {%- if p.preprint_url and p.preprint_url != "" -%}{%- assign citable = true -%}{%- endif -%} {%- if p and citable -%} {%- assign authlist = p.authors | replace: '*', '' | replace: '†', '' | replace: '‡', '' | split: ',' -%} {%- for a in authlist -%}{%- assign an = a | strip -%}{%- if an != "" and an != "..." and an != "…" %} {% endif -%}{%- endfor -%} {%- if p.journal and p.journal != "" %} {% endif -%} {%- if p.vol %} {% endif -%} {%- if p.issue and p.issue != "" %} {% endif -%} {%- if p.pages and p.pages != "" -%} {%- assign pp = p.pages | split: '-' %} {%- if pp.size > 1 %} {% endif -%} {%- endif -%} {%- if p.year %} {% endif -%} {%- if p.doi and p.doi != "" %} {% endif -%} {%- endif -%} {%- endif -%}
